# Creating Groups

This guide explains how to create and manage a Secret Santa group.

## Creating a New Group

### Step 1: Start the Process

1. From your dashboard, click **Create Group**
2. Or navigate to `/groups/new`

### Step 2: Fill in Group Details

**Required:**
- **Group Name** - Give your exchange a memorable name (e.g., "Smith Family 2024", "Office Holiday Exchange")

**Optional:**
- **Description** - Add context about the exchange
- **Currency** - Choose from USD, EUR, GBP, CAD, AUD, or JPY
- **Budget Range** - Set minimum and/or maximum gift values
- **Exchange Date** - When the gift exchange will happen

### Step 3: Create the Group

Click **Create Group** and you're done! You'll be redirected to your new group's dashboard.

## Your Invite Code

When your group is created, a unique 8-character invite code is automatically generated (e.g., `SANTA24X`).

Share this code with participants so they can join. You can find it:
- On your group dashboard
- In the invite section of the sidebar

You can also copy a shareable link that includes the code.

## Managing Your Group

As the group creator, you're automatically an **admin** with these capabilities:

### Member Management
- View all members and their roles
- Remove members if needed (before the draw)

### Exclusion Rules
- Set up exclusion rules to prevent certain matches
- [Learn more about exclusions](./the-draw.md#exclusion-rules)

### The Draw
- Initiate the Secret Santa draw
- Reset the draw if needed (before the exchange date)
- [Learn more about the draw](./the-draw.md)

### Event Details
- Set the exchange location
- Add event notes (parking, dress code, etc.)
- Add virtual meeting link for online exchanges
- [Learn more about events](./events.md)

### Group Settings
- Edit group name and description
- Update budget and exchange date
- Archive the group after the exchange

## Best Practices

### Before Sharing the Code
1. Double-check your group settings
2. Set a realistic exchange date
3. Decide on budget limits

### After Members Join
1. Give everyone time to join before drawing
2. Set up exclusion rules if needed
3. Remind members to add their wishlists

### After the Draw
1. Set event details for the exchange
2. Monitor RSVPs
3. Answer member questions

## Group Lifecycle

1. **Setup** - Create group and configure settings
2. **Invitation** - Share code, members join
3. **Preparation** - Set exclusions, members add wishlists
4. **Draw** - Run the Secret Santa draw
5. **Shopping** - Members buy gifts
6. **Exchange** - The big day!
7. **Archive** - Save memories for history
