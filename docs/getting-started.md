# Getting Started

This guide will walk you through signing up and setting up your first Secret Santa exchange.

## Signing In

Secret Santa uses Google authentication for a secure, hassle-free login experience.

1. Visit the Secret Santa homepage
2. Click **Sign in with Google**
3. Select your Google account
4. You'll be redirected to your dashboard

That's it! Your account is automatically created on first sign-in.

## Your Dashboard

After signing in, you'll see your personalized dashboard with:

- **Quick Actions** - Create or join a group
- **Upcoming Exchanges** - Your next Secret Santa events
- **Pending Draws** - Groups waiting for the draw (if you're an admin)

## Setting Up Your Profile

Before joining exchanges, take a moment to set up your profile:

1. Click your avatar in the top-right corner
2. Select **Profile**
3. Add your **interests** (hobbies, favorite things, etc.)
4. Write a brief **bio** about yourself

Your profile helps your Secret Santa find the perfect gift and enables better AI suggestions.

## Two Ways to Participate

### Option 1: Create a Group

If you're organizing the exchange:

1. Click **Create Group** on your dashboard
2. Fill in the group details (name, budget, date)
3. Share the invite code with participants
4. Run the draw when everyone has joined

[Learn more about creating groups](./creating-groups.md)

### Option 2: Join a Group

If someone invited you:

1. Get the 8-character invite code from the organizer
2. Click **Join Group** on your dashboard
3. Enter the code and click **Join**
4. Wait for the admin to run the draw

[Learn more about joining groups](./joining-groups.md)
