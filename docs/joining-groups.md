# Joining Groups

This guide explains how to join an existing Secret Santa group.

## Getting the Invite Code

Before you can join, you need an **8-character invite code** from the group organizer.

The code looks like: `SANTA24X` or `HLDYX123`

You might receive this:
- As a text message
- In an email
- As a link like: `yoursite.com/groups/join?code=SANTA24X`

## How to Join

### Method 1: Using the Dashboard

1. Sign in to your account
2. Click **Join Group** on your dashboard
3. Enter the 8-character code
4. Click **Join Group**

### Method 2: Using a Direct Link

If you received a link with the code:

1. Click the link
2. Sign in if prompted
3. The code will be pre-filled
4. Click **Join Group**

### Method 3: Manual Navigation

1. Go to `/groups/join`
2. Enter the invite code
3. Click **Join Group**

## What Happens After Joining

Once you join successfully:

1. You'll see a preview of the group (name, member count)
2. After clicking join, you become a **member**
3. You're redirected to the group dashboard
4. You can now:
   - View other members
   - Add items to your wishlist
   - See group details and budget

## Before the Draw

While waiting for the draw:

1. **Set up your wishlist** - Help your Secret Santa find great gifts
2. **Update your profile** - Add interests and a bio
3. **Check the budget** - Note the min/max gift values
4. **Mark your calendar** - Save the exchange date

## After the Draw

Once the admin runs the draw:

1. You'll receive a notification
2. Visit the group to reveal your assignment
3. Check your recipient's wishlist
4. Start shopping for the perfect gift!

## Viewing Your Groups

To see all groups you've joined:

1. Click **My Groups** on your dashboard
2. Or navigate to `/groups`

Each group shows:
- Group name
- Member count
- Exchange date
- Draw status
- Your role (admin or member)

## Troubleshooting

### "Invalid code" error
- Double-check the code for typos
- Codes are case-insensitive
- Make sure the code hasn't expired

### "Group not found" error
- The group may have been deleted
- Ask the organizer for a new code

### "Already a member" error
- You've already joined this group
- Find it in your groups list

### Can't find the join option
- Make sure you're signed in
- Check that you're on the correct page
